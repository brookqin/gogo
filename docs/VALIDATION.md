# 第一版验证记录

日期：2026-09-16。

## 已完成

- 环境：macOS 27.0（26A428）、Xcode 27.0（27A266a）、Apple Silicon。
- Swift Testing：8 项通过，覆盖特殊字符/中文/换行路径、参数数组、多目录语义、终端父目录去重、配置读写、配置损坏保护、未来版本拒绝、请求编码与非法输入。
- 主程序与 Finder 扩展的 unsigned Debug 编译通过，最低部署版本设置为 15.7。
- unsigned Release 通用二进制编译通过，主程序与扩展均包含 arm64、x86_64；这仅验证构建，不等于在 Intel 或旧系统上运行通过。
- 两套 `Localizable.strings` 均包含 91 个键，键集合一致。
- 本地 ad-hoc 签名后以 `--preview` 启动原生窗口成功；系统无障碍树包含中文侧栏、启动项开关、路径选择、编辑方式、保存/取消等控件，并观察到 Terminal/iTerm2 选择对应的编辑面板。
- 选定草图与独立透明图标已归档；ICNS 通过标准 `sips`/`iconutil` 生成。

## 发布前验收清单

1. 两个 target 使用同一团队和匹配的 App Group 签名，安装到 Applications 后首次打开。
2. 主程序保存配置，扩展菜单重开后读取到新的顺序、启用状态与语言。
3. 分别验证所选文件、所选文件夹、右键空白处、侧栏、工具栏、无可用目录、多窗口。
4. 每个内置应用验证冷启动和运行中行为；iTerm2 覆盖自动化许可允许与拒绝。
5. 自定义 `.app` 和 CLI 覆盖参数、工作目录、空格、引号、中文、换行和多选。
6. 配置缺失、损坏、未知版本、应用被移走时仍可恢复，不出现空白菜单或覆盖配置。
7. 分别记录 15.7、26、27 的系统版本/构建号与实机证据，验证关闭配置窗口及按需启动完成后的进程退出。
8. 完成 Developer ID 签名、公证、安装包及下载后的独立安装验证，再标记支持版本。
